## Checks and limits

The repository's build, deterministic regression suite, context lint and package checks cover generated definitions, local links, skill discovery and blank context. The qualification examples are validated for schema shape and basic fit-decision consistency. They are hand-authored calibration examples, not evidence that an AI model made the decisions correctly.

The OXYGEN CLI was inspected for `tables watcher preview/create/get/pause`, `columns add/run`, and Function binding. Setup instructions use the documented prompt-file and output-schema-file inputs. No live watcher, paid model run, auto-run or Sequence was created or activated for this addition. A reader still needs to preview their own configuration and calibrate their actual data.

The Notion page was fetched through its connector and loaded anonymously in a browser. It is readable. Duplication was not confirmed, so the guide includes a complete alternative using the bundled blank schema. No changes were made to the public Notion page or any reader's board.

The graphic is a dense reference intended for zooming. Its supplied performance headline describes Tim's example, not a forecast. PNG/GIF decoding, dimensions and asset hashes are checked before delivery.
